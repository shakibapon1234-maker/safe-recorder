SAFE RECORDER v1 (Windows)

চালানোর নিয়ম (একবারই):
1. nodejs.org থেকে Node.js LTS ইনস্টল করুন (আগে থেকে থাকলে লাগবে না)।
2. এই ফোল্ডারে (যেখানে package.json আছে) Address bar-এ cmd লিখে Enter দিন।
3. লিখুন:  npm install     (কয়েক মিনিট লাগবে, ইন্টারনেট লাগবে)
4. তারপর:  npm start

.exe বানাতে চাইলে:  npm run build   (dist ফোল্ডারে portable exe আসবে)

হটকি (যেকোনো প্রোগ্রামের ওপর থেকে কাজ করে):
F9  = রেকর্ড শুরু/বন্ধ
F10 = ব্লার ON/OFF
F8  = ব্লার এলাকা আঁকা (রেকর্ডিং চলার সময়ও আঁকা যায়)

ফাইল সেভ হয়: Videos\SafeRecorder
কিছু জরুরি কথা:
- অ্যাপের উইন্ডো ও এলাকা-আঁকার স্ক্রিন রেকর্ডিংয়ে আসে না।
- ব্লার শুধু রেকর্ড করা ভিডিওতে থাকে; আপনি স্ক্রিনে আসল তথ্যই দেখেন। প্রিভিউতে ব্লার-সহ দেখা যায়।
- ব্লার এলাকা স্ক্রিনের নির্দিষ্ট জায়গায় স্থির থাকে (স্ক্রলের সাথে সরে না)। স্ক্রল হওয়া জায়গার জন্য পুরো প্যানেলটা বক্সে ঢেকে দিন।
- শুধু প্রধান (primary) মনিটর রেকর্ড হয়।
